# Photography Company Brand Identity

A graphic design project focused on creating a visual identity for a fictional photography company.

## Overview

The project involved designing promotional materials for an imaginary photography business. The goal was to create a consistent visual identity across different business materials.

## Deliverables

- Promotional flyer
- Business card

## Technology

- GIMP

## Skills Practiced

- Graphic design
- Visual composition
- Typography
- Layout
- Branding
- Consistent visual identity

## Purpose

This project demonstrates practical experience with basic graphic design and visual communication using GIMP.
